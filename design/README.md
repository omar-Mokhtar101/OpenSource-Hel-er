# OpenPath brand assets

| File | Use |
|---|---|
| `openpath-mark.svg` | UI mark, inherits `currentColor`. Rendered by `apps/web/components/logo.tsx`. |
| `openpath-icon.svg` | App icon / social avatar, 512×512. Copied to `apps/web/public/openpath-icon.svg`. |

The mark is an open ring with a path leaving through the gap: an unfinished
route that the contributor finishes. It stays legible at 16 px because it is
two strokes and a gap, with no fine detail.

Favicon: `apps/web/app/icon.svg` (Next.js serves it automatically).
